FxSound DSP Tutorial

Play piano notes, see them as raw 24-bit PCM samples, then watch what each stage of the FxSound audio engine does to the waveform. Every effect here runs the same math as the FxSound engine, ported sample-for-sample from its C source.

1 Make some raw PCM audio

Each key adds a half note (1 second at 120 bpm, 4/4) to the melody. The melody is synthesized, scaled to the peak level you choose, and stored as 44.1 kHz, 24-bit, stereo PCM.

Which frequency is each key?

Equal temperament with A4 = 440 Hz: each key is 21/12 (about 1.059) times the frequency of the key a semitone below, so every octave doubles the frequency. Black keys are not on this keyboard but still count as semitones. Frequencies in Hz:

4 Isolate a processing stage

FxSound runs these stages in this exact order on every buffer of audio. Untick a stage to remove just that stage and see (and hear) what it was doing. These switches exist only in the tutorial.
